Sem Docker: instale Python 3.11 ou superior e execute run.bat no Windows ou ./run.sh no Linux/macOS.

O script instala as dependências e inicia a aplicação em http://127.0.0.1:8501.

Com Docker: execute docker compose up -d --build e abra o mesmo endereço.
Para usar IA na leitura de texto livre, instale o Ollama e execute ollama pull qwen3.5:9b.

Para planilhas, a IA é opcional. No Linux com Docker, siga os comandos específicos do [README](README.md).
